# 🧪 DarkDate: Руководство по запуску тестов в браузере

Этот документ описывает, как запустить PHP-тесты для API проекта DarkDate прямо в браузере на хостинге Timeweb (или любом другом PHP-хостинге).

## 📋 Список тестов

| Файл | Описание | URL для запуска |
|------|----------|-----------------|
| `01_auth_test.php` | Тест регистрации, логина, создания сессии и logout | `/tests/01_auth_test.php` |
| `02_chat_bot_test.php` | Тест чата с ботом, отправка сообщений, проверка ответов | `/tests/02_chat_bot_test.php` |
| `03_story_fear_test.php` | Тест механики страха, прогресса сюжета, уведомлений | `/tests/03_story_fear_test.php` |

---

## 🚀 Быстрый старт

### Шаг 1: Подготовка базы данных

Перед запуском тестов убедитесь, что база данных создана и таблицы импортированы:

```bash
# Подключитесь к MySQL
mysql -u ваш_пользователь -p

# Создайте базу данных
CREATE DATABASE darkdate CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# Импортируйте структуру
USE darkdate;
source /path/to/sql/darkdate_schema.sql;

# Импортируйте начальные данные ботов
source /path/to/sql/bots_seed.sql;
```

### Шаг 2: Настройка config/database.php

Откройте файл `/workspace/config/database.php` и замените плейсхолдеры на ваши реальные данные:

```php
class Database {
    private $host = "localhost";        // или адрес вашего MySQL сервера
    private $db_name = "darkdate";      // имя вашей БД
    private $username = "ваш_user";     // пользователь БД
    private $password = "ваш_password"; // пароль БД
    // ...
}
```

### Шаг 3: Загрузка файлов на хостинг

Загрузите все файлы проекта на ваш хостинг Timeweb:

```
/public_html (или ваша корневая папка)
├── config/
│   └── database.php
├── api/
│   ├── auth.php
│   ├── chat.php
│   ├── story.php
│   └── bots.php
├── tests/
│   ├── 01_auth_test.php
│   ├── 02_chat_bot_test.php
│   ├── 03_story_fear_test.php
│   └── README_TESTS.md
├── sql/
│   ├── darkdate_schema.sql
│   └── bots_seed.sql
└── docs/
    └── CONTENT_PLAN.md
```

Откройте браузер и перейдите по соответствующим URL:

## 🎨 Как выглядят результаты тестов

Каждый тест выводит результат в формате:

```
✅ Название теста
   Дополнительная информация (зелёный цвет)

❌ Название теста
   Сообщение об ошибке (красный цвет)
```

В конце каждого теста показывается итоговая панель со статистикой и SQL-запросами для очистки тестовых данных.

---

## 🧹 Очистка тестовых данных

После каждого теста в нижней части страницы показываются SQL-команды для удаления тестовых данных. Пример:

```sql
DELETE FROM darkdate_messages WHERE user_id = 123;
DELETE FROM darkdate_sessions WHERE user_id = 123;
DELETE FROM darkdate_users WHERE username = 'testuser_1234567890';
```

Выполните эти команды в phpMyAdmin или через консоль MySQL чтобы очистить базу данных.

## 🐛 Решение проблем

### Ошибка: "Database connection failed"

**Причина:** Неправильные учётные данные в `config/database.php`

**Решение:**
1. Проверьте что файл `config/database.php` содержит правильные данные
2. Убедитесь что пользователь БД имеет права на доступ к базе данных
3. Проверьте что MySQL сервер доступен

---

### Ошибка: "Table 'darkdate_users' doesn't exist"

**Причина:** Таблицы не созданы в базе данных

**Решение:**
```bash
mysql -u user -p darkdate < sql/darkdate_schema.sql
mysql -u user -p darkdate < sql/bots_seed.sql
```

---

### Ошибка: "Class 'Database' not found"

**Причина:** Файл `config/database.php` не найден или путь указан неверно

**Решение:**
1. Убедитесь что файл существует по пути `/config/database.php`
2. Проверьте что в тестах указан правильный путь: `require_once '../config/database.php';`

---

### Ошибка: "Access denied for user"

**Причина:** Пользователь БД не имеет прав

**Решение:**
```sql
GRANT ALL PRIVILEGES ON darkdate.* TO 'your_user'@'localhost';
FLUSH PRIVILEGES;
```

## 🔐 Безопасность

**ВАЖНО:** Не оставляйте тестовые файлы на продакшене!

После завершения тестирования:
1. Удалите файлы из папки `/tests/` или ограничьте доступ к ним
2. Или добавьте защиту по IP/паролю в начало каждого файла:

```php
// Защита тестовых файлов
$allowed_ips = ['127.0.0.1', 'YOUR_IP'];
if (!in_array($_SERVER['REMOTE_ADDR'], $allowed_ips)) {
    die('Access denied');
}
```

4. Проверьте что расширения PDO и pdo_mysql включены
