# CHANGELOG — DarkDate

> Первое правило: все изменения записываются сюда.

## [0.1.0] — 2026-06-24

### Добавлено
- Инициализация проекта DarkDate
- Модульная архитектура (HTML + CSS + JS)
- Основной экран свайпов (Tinder-style UI)
- Тёмная тема (чёрный + красный акцент)
- Механика свайпов: drag & drop + кнопки (лайк/дизлайк)
- Система попыток: 3 на раунд, 3 на сессию, таймер 4 часа
- 10 тестовых профилей (5 людей, 3 сущности, 1 жертва, 1 охотник)
- Базовые хоррор-эффекты: глитч CSS, тряска экрана, затемнение
- Система дебаффов зрения (темнота + фонарик)
- i18n модуль (RU + EN)
- Логотип: сердце с трещиной (красно-чёрная палитра)
- Адаптивный дизайн (mobile-first, стилизация под телефон)
- localStorage для сохранения состояния

### Архитектура
- `src/core/` — ядро (state, events)
- `src/modules/` — модули (swipe, horror, ui, i18n)
- `src/data/` — данные (profiles, translations)
- `src/assets/` — ресурсы (images, audio)
- Модульная система через ES6 modules

### Технический стек
- Frontend: HTML5 + CSS3 + Vanilla JS (ES6 modules)
- Backend (планируется): PHP + MySQL 5
- WebSocket (планируется): Node.js + Socket.IO
- Хостинг: Timeweb (тариф Year)
- Платежи (планируется): ЮKassa
