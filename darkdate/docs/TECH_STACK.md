## 📋 Обзор технологий

DarkDate построен на **минималистичном стеке** без использования тяжёлых фреймворков. Это обеспечивает быструю загрузку, простоту разработки и лёгкость развёртывания.

| Категория | Технология | Версия | Зачем используется |
|-----------|-----------|--------|-------------------|
| **Язык** | JavaScript | ES6+ (ES2015+) | Основной язык приложения |
| **Стили** | CSS3 | Latest | Стилизация, анимации, эффекты |
| **Разметка** | HTML5 | Latest | Структура приложения |
| **Аудио** | Web Audio API | Native | Генерация звуковых эффектов |
| **Хранение** | localStorage | Native | Сохранение прогресса игрока |
| **Сборка** | Не требуется | — | Приложение работает без сборки |

## 🎯 Ключевые решения

### 1. Ванильный JavaScript (без фреймворков)

**Почему:**
- ✅ Быстрая загрузка (нет bundle размером в мегабайты)
- ✅ Простота понимания кода (нет абстракций фреймворка)
- ✅ Легко развернуть (просто статические файлы)
- ✅ Полный контроль над производительностью
- ✅ Идеально для прототипа и MVP

**Что используется из ES6+:**
- `class` — для создания модулей
- `import/export` — модульная архитектура
- `async/await` — асинхронные операции
- `const/let` — блочная область видимости
- Arrow functions, template literals, деструктуризация

---

### 2. CSS3 с современными возможностями

**Используемые функции:**
- **CSS Custom Properties (Variables)** — для темизации и динамических значений
  ```css
  --flash-x: 200px;
  --flash-y: 300px;
  ```

- **CSS Animations & Keyframes** — для плавных переходов
  ```css
  @keyframes glitch { ... }
  .card-menace { animation: pulse 2s infinite; }
  ```

- **CSS Transform** — для производительных анимаций (аппаратное ускорение)
  ```css
  transform: translate(100px, 0) rotate(30deg);
  ```

- **Flexbox & Grid** — для адаптивной вёрстки

- **Backdrop Filter** — для эффектов размытия
  ```css
  backdrop-filter: blur(10px);
  ```

---

### 3. Web Audio API для звука

**Почему не аудиофайлы:**
- ✅ Нет внешних зависимостей (MP3/WAV файлов)
- ✅ Мгновенная генерация звука (нет загрузки)
- ✅ Полный контроль над параметрами (частота, длительность, фильтр)
- ✅ Минимальный размер приложения

**Что генерируется:**
- **Drone (гул)** — низкочастотный осциллятор (пилообразная волна)
- **Whisper (шёпот)** — белый шум + полосовой фильтр
- **SFX** — могут быть добавлены аналогично

**Пример:**
```javascript
const osc = audioContext.createOscillator();
osc.type = 'sawtooth';
osc.frequency.setValueAtTime(60, audioContext.currentTime);
```

---

### 4. localStorage для сохранения прогресса

**Что сохраняется:**
- Состояние игры (жизни, таймеры)
- Статистика игрока
- Выбранный язык
- Время восстановления жизней

**Преимущества:**
- ✅ Работает offline
- ✅ Нет необходимости в бэкенде
- ✅ Мгновенное сохранение/загрузка
- ✅ Данные сохраняются между сессиями

**Структура данных:**
```json
{
  "sessionLives": 3,
  "recoveryEndTime": 1719748800000,
  "stats": { ... },
  "lastSave": 1719745200000
}
```

---

### 5. Модульная архитектура (ES6 Modules)

**Структура:**
```
app.js (главный модуль)
├── core/state.js
├── modules/swipe.js
├── modules/horror.js
├── modules/ui.js
└── modules/i18n.js
```

**Импорты:**
```javascript
import { GameState } from './core/state.js';
import { SwipeEngine } from './modules/swipe.js';
```

**Преимущества:**
- Чёткое разделение ответственности
- Легко тестировать отдельные модули
- Простота расширения (добавить новый модуль)
- Нет глобальных переменных (кроме `window.darkdate` для отладки)

## 📱 Mobile-first подход

### Адаптивность

- **Viewport meta tag** для правильного масштабирования:
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
  ```

- **CSS-единицы:**
  - `vh/vw` — для адаптивных размеров
  - `rem` — для шрифтов
  - `%` — для гибкой вёрстки

- **Touch-события:**
  - `touchstart`, `touchmove`, `touchend` — для свайпов
  - `passive: false` — для предотвращения скролла

- **Кнопки:**
  - Минимальный размер 44×44px (рекомендация Apple Human Interface Guidelines)

## 🎯 Почему этот стек подходит для DarkDate

1. **Быстрый старт** — не нужно устанавливать зависимости
2. **Легко учиться** — код понятен даже новичкам
3. **Производительность** — нет накладных расходов фреймворков
4. **Гибкость** — полный контроль над каждой строчкой кода
5. **Дешёвый хостинг** — статические файлы = бесплатный хостинг
6. **Идеально для MVP** — можно быстро протестировать идею

> **Философия:** Использовать минимум инструментов для достижения максимума результата.
