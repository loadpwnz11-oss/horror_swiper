## 1. Концепция

**DarkDate** — казуальная хоррор-игра в формате swipe-приложения для знакомств. Игрок использует вымышленное приложение, где среди обычных людей скрываются сущности, жертвы и охотники. Цель — выжить, распознавая угрозу, и не потерять рассудок.

**Жанр:** Casual Horror / Swipe / Dating Sim  
**Платформы:** Web (Mobile-first, Desktop), возможно Telegram-бот  
**Поджанр хоррора:** Микс — психологический + слэшер + мета-хоррор  
**Возрастной рейтинг:** 12+ (базовая версия), 16+ и 18+ — отдельные DLC-сюжеты

### 1.1 Уникальность
- Формат "приложения в приложении" — полная имитация Tinder
- Реалистичные фото людей + uncanny valley для сущностей
- Мета-хоррор: игра "узнаёт" игрока (имя, время, система)
- Мультиплеер: дуэли, ко-оп, рейтинги
- Модульная структура — легко добавлять новые сюжеты (DLC)

## 3. Геймплей

### 3.1 Основной цикл

```
[Запуск] → [Лента профилей] → [Свайп влево/вправо] → [Результат]
      ↑                                              ↓
      └────── [Конец раунда / Game Over] ←───────────┘
```

### 3.2 Действия игрока

| Действие | Жест | Кнопка | Эффект |
|----------|------|--------|--------|
| Лайк | Свайп вправо | ❤️ | Принять профиль, начать чат |
| Дизлайк | Свайп влево | ❌ | Отклонить профиль |
| Суперлайк | Свайп вверх | ⭐ | (Фаза 2) Особое действие |
| Просмотр деталей | Тап по карточке | — | Увеличить фото, увидеть больше |
| Блокировка | Кнопка 🛡️ | — | (Фаза 2) Против спамер-ботов |

### 3.3 Система жизней

**Двухуровневая система:**

| Уровень | Значение | Восстановление |
|---------|----------|----------------|
| **Раунд** | 3 жизни | Сбрасывается каждый раунд |
| **Сессия** | 3 жизни (+1 за покупку) | 4 часа таймера → +2 жизни |

**Покупки (опционально):**
- +1 жизнь за рекламу (2 попытки за просмотр)
- +1 жизнь за внутриигровую валюту
- Подписка: маленькие надбавки каждый месяц

## 4. Типы профилей

### 4.1 Классификация

| Тип | Свайп → | Свайп ← | Описание |
|-----|---------|---------|----------|
| **Человек** | Чат начинается | Просто пропуск | Обычный NPC или реальный игрок |
| **Сущность** | ❌ Потеря жизни | ✅ Безопасно | Маскируется под человека |
| **Жертва** | ✅ Спасение | ⚠️ Погибает | Моральная дилемма, не теряет жизнь |
| **Охотник** | ✅ Чат + подсказка | Пропуск | Даёт полезную информацию |
| **Спамер-бот** | ⚠️ Спамит 10 сек | Пропуск | Если не заблокировать → урон |

### 4.2 Признаки сущностей (подсказки игроку)

**Тонкие намёки:**
- Странное описание, повторяющиеся слова
- Нелогичные фото, глитчи при просмотре
- Отсутствующая фамилия, странный возраст
- Зацикленные фразы в био

**Очевидные признаки (для внимательных):**
- Красные/нечеловеческие глаза
- Искажения на фото (только при долгом просмотре)
- Unicode-глитч символы в имени (Zalgo text)

**Полная маскировка:**
- Выглядит как человек, только поведение выдаёт
- Распознаётся только через чат или подсказки охотника

**Дебаффы зрения (активные угрозы):**
- Темнота + фонарик (следует за пальцем)
- Размытие зрения
- Инверсия цветов
- Статический шум

## 5. Хоррор-элементы

### 5.1 Визуальные эффекты

| Эффект | Триггер | Длительность |
|--------|---------|--------------|
| Глитч экрана | Сущность рядом, принятие | 0.3–2 сек |
| Тряска экрана | Принятие сущности, game over | 0.5–0.8 сек |
| Красная вспышка | Урон, скример | 0.5 сек |
| Темнота + фонарик | Дебафф сущности | 4–5 сек |
| Размытие зрения | Дебафф сущности | 4 сек |
| Статический шум | Хоррор-событие | 2 сек |
| Сканлайны (CRT) | Постоянно (опционально) | — |
| Пульсация карточки | Сложная сущность | Бесконечно |
| Мерцание текста | Глитч-био | Бесконечно |

### 5.2 Звуковые эффекты

| Звук | Триггер | Генерация |
|------|---------|-----------|
| Низкий гул (drone) | Принятие сущности | Web Audio API |
| Шёпот | Хоррор-событие | Белый шум + фильтр |
| Уведомление | Новый матч, сообщение | Предустановленный |
| Сердцебиение | Мало жизней | Web Audio API |
| Скример | Game over | Аудиофайл |

### 5.3 Мета-хоррор (ломание четвёртой стены)

**Фаза 1 (базово):**
- Использование имени игрока в диалогах
- Упоминание времени из системы ("Ты всё ещё не спишь в 3 ночи?")
- Ложные уведомления от "системы"

**Фаза 3 (продвинуто):**
- Обращение к файлам браузера (через API)
- "Скриншоты" интерфейса с искажениями
- Изменение названия вкладки
- Ложные системные сообщения

## 6. Мультиплеер

### 6.1 Режимы

| Режим | Тип | Описание |
|-------|-----|----------|
| **Одиночный** | — | Основной сюжетный режим |
| **Дуэль** | Синхронный | Два игрока, одна лента, кто первый ошибётся |
| **Гонка** | Синхронный | Кто быстрее найдёт сущность/спасёт жертву |
| **Чат с сущностью** | Синхронный | Кто дольше продержится в диалоге |
| **Ко-оп** | Синхронный | Два игрока голосуют за свайп вместе |
| **Рейтинг** | Асинхронный | Таблица лидеров по сессиям |

### 6.2 Лента профилей

**Микс:** NPC + реальные игроки в одной ленте
- Реальные игроки создают анкеты (как в настоящем Tinder)
- NPC генерируются процедурно
- Игрок не знает, кто есть кто

## 7. Сюжет и прогрессия

### 7.1 Структура контента

**Базовая версия (12+):**
- Обучение-сюжет: "Ты скачал странное приложение..."
- Финал обучения = концовка
- Покупка DLC-сюжетов для продолжения

**DLC-сюжеты (планируется):**
- "Школа" (16+)
- "Больница" (16+)
- "Подвал" (18+)
- "Космос" (18+)

### 7.2 Прогрессия игрока

**Уровни и опыт:**
- XP за каждый правильный свайп
- Уровни открывают новые функции приложения

**Разблокировки:**
- Новые "фишки" приложения (суперлайк, расширенное био)
- Новые темы оформления
- Коллекция найденных сущностей (бестиарий)
- Достижения (ачивки)

**Ежедневные бонусы:**
- Накопительная система (не просто +1 в день)
- Разнообразные награды (валюта, попытки, косметика)

## 8. Монетизация

### 8.1 Валюты

| Валюта | Получение | Использование |
|--------|-----------|---------------|
| **Мягкая** (Coins) | Игровой процесс | Косметика, мелкие покупки |
| **Твёрдая** (Gems) | Реальные деньги / редкие награды | Жизни, DLC, эксклюзив |

### 8.2 Способы монетизации

1. **Внутриигровые покупки (ЮKassa):**
   - Жизни
   - Валюта (Gems)
   - DLC-сюжеты
   - Косметика (темы, аватарки)

2. **Реклама:**
   - Rewarded Video: +2 попытки за просмотр
   - Interstitial: между раундами (ограниченно)

3. **Подписка:**
   - Ежемесячная плата
   - Маленькие надбавки (ежедневные бонусы x2, без рекламы)

### 8.3 Платёжная система

**Основная:** ЮKassa  
**Дополнительно (для международных):** Stripe, PayPal (в будущем)

## 11. Технические требования

### 11.1 Клиент
- **Браузер:** Chrome 90+, Safari 14+, Firefox 88+, Edge 90+
- **Устройства:** Mobile (iOS 13+, Android 8+), Desktop

### 11.3 Производительность
- First Contentful Paint: < 1.5 сек
- Время до интерактивности: < 3 сек
- FPS в игре: 60 fps
- Размер бандла: < 500 KB (без ассетов)

## 13. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| CORS при деплое | Средняя | Высокая | Правильная настройка сервера |
| Производительность на слабых устройствах | Средняя | Средняя | Оптимизация ассетов, lazy loading |
| Скучный геймплей | Средняя | Высокая | Плейтесты, баланс сложности |
| Слишком страшно для 12+ | Низкая | Высокая | Чёткие возрастные метки, настройки |
| Проблемы с платёжкой | Средняя | Высокая | Тестовый режим ЮKassa, fallback |
