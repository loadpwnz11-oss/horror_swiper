# DarkDate 👻

**Хоррор-игра в формате swipe-приложения для знакомств**

> Версия: 0.1.0 | Статус: Прототип

DarkDate — это казуальная хоррор-игра, где вы используете вымышленное приложение для знакомств. Среди обычных профилей скрываются сущности, жертвы и охотники. Ваша цель — выжить, распознавая угрозу, и не потерять рассудок.

![Логотип](darkdate/src/assets/icons/logo.svg)

---

## 🚀 Быстрый старт

```bash
# Просто откройте index.html в браузере
open darkdate/index.html
```

Или используйте локальный сервер:

```bash
# Python
cd darkdate && python3 -m http.server 8000

# Node.js
npx serve darkdate
```

## 🎮 Особенности игры

- **Формат "приложение в приложении"** — полная имитация Tinder
- **Реалистичные фото** + uncanny valley для сущностей
- **Мета-хоррор** — игра "узнаёт" игрока (имя, время, система)
- **Мультиплеер** — дуэли, ко-оп, рейтинги (в разработке)
- **Модульная структура** — легко добавлять новые сюжеты (DLC)

## 📦 Установка и запуск

### Требования
- Современный браузер (Chrome 90+, Safari 14+, Firefox 88+)
- Или локальный HTTP-сервер для разработки

### Запуск
1. Клонируйте репозиторий
2. Откройте `darkdate/index.html` в браузере
3. Или поднимите локальный сервер:
   ```bash
   cd darkdate
   python3 -m http.server 8000
   ```
4. Перейдите на `http://localhost:8000`
